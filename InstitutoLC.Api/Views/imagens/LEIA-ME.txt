INSTRUÇÕES PARA ADICIONAR O FAVICON
=====================================

Para usar a imagem do personagem de casa como favicon:

1. Salve a imagem nesta pasta com o nome "favicon.ico" ou "favicon.png"
2. Se a imagem estiver em outro formato (JPG, SVG, etc.), converta para ICO ou PNG
3. Formatos recomendados:
   - favicon.ico (formato tradicional, melhor compatibilidade)
   - favicon.png (formato moderno, melhor qualidade)

4. Tamanhos recomendados:
   - 16x16 pixels (mínimo)
   - 32x32 pixels (recomendado)
   - 64x64 pixels (alta qualidade)

5. Após adicionar o arquivo, o favicon aparecerá automaticamente em todas as páginas do sistema.

NOTA: Os arquivos HTML já estão configurados para usar o favicon desta pasta.
